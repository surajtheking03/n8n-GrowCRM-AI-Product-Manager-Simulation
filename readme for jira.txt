# 📡 GrowCRM Jira Listener (n8n)

The GrowCRM Jira Listener is a real-time event-driven automation system that tracks Jira issue movements and triggers actions across multiple channels.

---

## 💡 What It Does

- Listens to Jira issue updates using webhook triggers  
- Captures status changes in real time  
- Logs every movement into Google Sheets  
- Sends Slack notifications for each transition  
- Sends Gmail notification when a task reaches "Done"  

---

## ⚙️ Workflow Behavior

Every time a Jira issue changes status:

1. Webhook captures the event  
2. Data is parsed and structured  
3. Entry is logged into Google Sheets  
4. Slack message is triggered  
5. If status is "Done", Gmail notification is sent  

---

## 🔄 Flow Overview

Jira → Webhook → Google Sheets → Slack → Gmail

---

## 🛠 Setup Instructions

1. Import the `Jira_Listener.json` into n8n  
2. Copy the webhook URL generated by n8n  
3. Configure Jira Webhook:
   - Go to Jira Settings → Webhooks  
   - Paste the n8n webhook URL  
   - Enable issue update events  

4. Configure credentials:
   - Google Sheets  
   - Slack  
   - Gmail  

5. Replace placeholders:
   - YOUR_GOOGLE_SHEET_URL  
   - YOUR_SLACK_CHANNEL_ID  
   - YOUR_EMAIL_HERE  

6. Activate the workflow  

---

## 📊 Output

- Real-time Jira movement tracking  
- Structured logging in Google Sheets  
- Instant Slack updates  
- Final completion email alerts  

---

## 💎 Use Case

This module can be used independently in any project where:

## 🚀 Summary

The Jira Listener transforms Jira from a passive tracking tool into an active event-driven system that communicates, logs, and reacts automatically.
